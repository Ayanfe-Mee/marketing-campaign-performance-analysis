## Project Overview

Marketing campaigns generate large volumes of data, but identifying which factors influence campaign success requires structured analysis.

This project explores a marketing campaign dataset using Python to evaluate campaign performance across different campaign types and marketing channels. The analysis focuses on key marketing metrics such as Return on Investment (ROI), Click-Through Rate (CTR), Cost Per Click (CPC), impressions, clicks, and conversion rate.

The goal is to transform raw marketing data into actionable business insights that can support data-driven marketing decisions.

## Project Objectives

This project aims to:
- Clean and prepare marketing campaign data for analysis.
- Explore relationships between key marketing metrics.
- Compare campaign performance across campaign types and marketing channels.
- Identify trends affecting ROI and campaign efficiency.
- Provide business recommendations based on the findings.

## Dataset

The dataset contains over **200,000 marketing campaign records**, including:

- Campaign Type
- Marketing Channel
- Clicks
- Impressions
- Acquisition Cost
- Conversion Rate
- Engagement Score
- ROI
- Campaign Date

Feature engineering was also performed to calculate:

- Click-Through Rate (CTR)
- Cost Per Click (CPC)
- Monthly Campaign Trends

## Key Findings

- Campaign profitability remained relatively consistent across campaign types.
- Higher click volume was associated with lower cost per click.
- Increasing impressions did not necessarily improve click-through rate.
- ROI showed little correlation with any single marketing metric.
- Marketing channel had only a modest impact on campaign profitability.

## Recommendations

- Improve audience targeting rather than simply increasing impressions.
- Continuously test campaign-channel combinations.
- Monitor CPC alongside click volume to improve cost efficiency.
- Include revenue and customer lifetime value in future analyses.
